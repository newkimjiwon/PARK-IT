# 스마트폰 앱 — PARK-IT(파킷)

[Figma 프로토타입](figma-prototype-review.md)의 모바일 화면을 Android 앱으로 옮긴 것입니다. 코드는 `phone/` 모듈에 있습니다. 데이터 모델, 샘플 장소, 추천 로직, 사진 지도는 [차량용 앱](vehicle-app.md)과 함께 쓰는 `core/` 모듈에 있습니다.

> 확인 범위: 2026-11-05 Android 15(API 35) Pixel 7 에뮬레이터에서 빌드·설치·실행했습니다. 다음 흐름을 직접 눌러 확인했습니다.
> - 홈 피드, 지도, 장소 상세
> - 장소 공유 3단계(2026-11-14 순서 변경): 지도에서 위치 정하기 → 사진 선택 → 제목·테마·차박 여부(꿀팁·준비물·공개 범위는 '더 쓰기') → 게시. 게시한 장소가 지도에 표시되는 것까지 확인했습니다.
> - 차량 탭의 공조 켜기: 확인 창 → 처리 중 → 결과
> - 마이 탭
>
> 단위 테스트 10개(core 9, phone 1)가 통과했습니다. 기기 갤러리에서 사진 고르기, 사진의 GPS 위치 읽기, 댓글·꿀팁 제보 저장, 쇼핑 검색 열기는 직접 확인하지 않았습니다. 한글 입력도 확인하지 않았습니다(테스트 입력은 영문).

## 빌드와 실행

macOS:

```zsh
sh gradlew :phone:assembleDebug :phone:testDebugUnitTest
adb install -r phone/build/outputs/apk/debug/phone-debug.apk
adb shell am start -n com.nangmanroad.phone/.MainActivity
```

Windows PowerShell:

```powershell
.\gradlew.bat :phone:assembleDebug :phone:testDebugUnitTest
adb install -r phone\build\outputs\apk\debug\phone-debug.apk
adb shell am start -n com.nangmanroad.phone/.MainActivity
```

휴대폰 에뮬레이터가 없으면 Android Studio의 Device Manager에서 Pixel 계열 기기를 만듭니다. 시스템 이미지는 API 35 Google APIs, Apple Silicon에서는 arm64-v8a를 고릅니다. 이 Mac에서는 `NangmanRoad_Phone`(Pixel 7, `system-images;android-35;google_apis;arm64-v8a`)을 만들어 썼습니다. 차량용 Pleos 에뮬레이터와 동시에 실행할 수 있습니다. `adb devices`에서 각 기기의 번호를 확인한 뒤 `adb -s 번호 ...`로 대상을 지정합니다.

## 화면과 기능

| 탭·화면 | 동작 |
| --- | --- |
| 홈 | 피드입니다. 나를 위한 추천, 팔로잉, 가까운 곳 탭이 있습니다. 게시물 사진을 좌우로 넘길 수 있고 좋아요, 댓글, 차로 보내기, 꿀팁, 저장 버튼이 있습니다. 첫 게시물 아래에 '가까운 곳' 가로 목록을 보여줍니다. |
| 알림 | 댓글, 답변, '도움이 됐어요', 팔로우 알림 예시입니다. 누르면 관련 장소로 이동합니다. |
| 지도 | 차량 앱과 같은 사진 지도를 휴대폰 크기로 보여줍니다. 분류 필터가 있고, 마커를 누르면 하단 미리보기 카드가 나옵니다. |
| 장소 상세 | 사진 갤러리, 작성자 팔로우, 좋아요, 저장, '다녀왔어요', 차량으로 보내기가 있습니다. 탭은 꿀팁, 아이템, 댓글 세 가지입니다. |
| 꿀팁 | 같은 종류의 꿀팁끼리 내용이 엇갈리면 모두 '확인 필요'로 표시합니다. '도움이 됐어요'를 누를 수 있고, '꿀팁 제보하기'로 종류·상태·요약·설명을 남깁니다. |
| 준비물 | 방문자들이 챙겨 간 물건입니다. 추천한 사람, 이유, 가격, 광고·제휴 표시가 있습니다. '관심 상품 담기'로 저장하고, '쇼핑 검색'은 상품 이름으로 네이버 쇼핑 검색을 엽니다. 샘플 상품에는 실제 판매처 링크가 없기 때문입니다. |
| 댓글 | 후기와 질문을 골라 남길 수 있고, 각 댓글에 답글을 달 수 있습니다. 내가 쓴 댓글은 맨 위에 표시됩니다. |
| 파킷 받기 | 알림의 '차량에서 보낸 항목'에 차량이 세운 위치가 핀 아이콘으로 옵니다. 새 장소면 누르는 순간 그 위치가 찍힌 장소 공유가 시작되고(2단계에 "차량이 세운 위치를 받았어요" 안내), 게시하면 알림에서 사라집니다. 차량에서 '말로 메모'를 남겼으면 알림에 따옴표로 보이고, 장소 공유의 경험 글에 미리 들어갑니다. 알려진 장소면 그 장소의 꿀팁 화면이 열립니다. |
| 장소 공유 | 세 단계입니다. ① 어디였나요: '내 위치에서 시작'(권한을 거부해도 지도에서 찍을 수 있음), 시·군 검색, 지도에 핀 찍기. 지역을 고르면 지도가 그 지역으로 이동하고 임시 핀이 중심에 놓이며, 지도를 누르면 그 좌표가 저장됩니다. 이미 올라온 장소의 사진을 누르거나 300m 안에 핀을 찍으면 '이 장소에 후기 남기기'로 연결되어 새 장소가 중복 생성되지 않습니다. 위치 공개 수준(정확한 위치/시·군까지만)도 여기서 고릅니다. ② 사진: 기기 갤러리나 샘플 사진에서 고르기 ③ 어떤 곳이었나요: 제목·경험·테마·차박 가능 여부·방문 조건·가기 좋은 때. 꿀팁, 준비물, 공개 범위는 '더 쓰기' 칩을 눌러야 펼쳐지고 모두 선택 사항입니다. 준비물은 이름이나 써 본 이유 중 하나만 적어도 추가되고, 직접 구매/광고·제휴 선택은 없습니다. |
| 차량 | **콘셉트 화면**입니다. 모델명 아래에 큰 배터리 숫자와 얇은 막대, 주행 가능 거리, 그리고 도어·창문·실내 온도·공조를 구분선으로 나눈 사양표가 있습니다. 주의할 값(열린 문·창문)만 주황색입니다. 도어 잠금·해제, 공조 켜기·끄기(목표 온도 조절), 창문 닫기는 확인 창 → 처리 중 → 결과 순서로 진행됩니다. 무드 조명은 '지원하지 않아요'로 비활성화되어 있습니다. '차량으로 보낸 장소' 목록도 여기서 봅니다. |
| 마이 | 공유한 장소, 방문 완료, 받은 좋아요, 기여한 꿀팁, 팔로잉 수를 보여줍니다. '내 장소 지도'는 공유한 곳(노란색), 저장한 곳(파란색), 방문 완료(초록색)를 테두리 색으로 구분합니다. 아래에 탭별 목록이 있습니다. |

데모 계정은 샘플 작성자 '윤슬을따라'입니다. 게시물, 댓글, 제보한 꿀팁은 JSON으로, 저장·좋아요·팔로우·방문 완료·관심 상품·차량으로 보낼 목록은 `SharedPreferences`로 기기 안에 저장됩니다. 고른 사진은 앱 저장소(`files/posts/`)로 복사합니다.

## 차량 원격 제어를 콘셉트로 둔 이유

Pleos Connect SDK는 차량 안의 Android Automotive 앱에서 차량 정보를 읽고 제어하는 구조입니다. 휴대폰에서 차량을 원격으로 조회·제어하는 공개 SDK는 확인되지 않았습니다. Vehicle Control SDK는 2026-11-05 기준 '준비 중' 상태입니다([SDK 사용 안내](https://document.pleos.ai/docs/pleos-only/create-my-project)). 그래서 차량 탭의 값과 명령 결과는 모두 앱 안에서 만든 예시이고, 화면 상단 안내와 '(데모)' 표시로 이를 밝힙니다. 승인된 연동 수단이 생기면 `PhoneViewModel.confirmCarCommand`의 시뮬레이션 부분을 실제 호출로 바꾸면 됩니다.

## 코드 구조

```
phone/src/main/java/com/nangmanroad/phone/
├── MainActivity.kt, PhoneViewModel.kt   화면 상태, 탭·화면 이동, 공유 초안, 차량 데모 명령
├── data/                                내 게시물·댓글·꿀팁 저장(PostStore), 시·군 목록, 차량 데모 상태
└── ui/                                  홈, 지도, 상세, 장소 공유, 차량, 마이, 알림, 공용 컴포넌트, 테마
```

색, 글꼴, 디자인 원칙은 차량 앱과 같습니다([차량용 앱 문서](vehicle-app.md) 참고). 휴대폰에서 진한 그린(Pine)은 화면마다 하나뿐인 주요 버튼(로그인 '시작하기', 장소 상세 '차량으로 보내기', 장소 공유 '다음 단계')과 지도에서 고른 장소에만 씁니다. 하단 탭의 '장소 공유'는 글자색과 같은 진한 버튼입니다.

## 아직 없는 것

- 실제 인증과 운영 서버. 계정·차량 연결·동기화는 [동기화 서버](sync-server.md)로 동작하지만, 개발용이라 닉네임만으로 로그인합니다.
- 실제 위치. 거리는 서울시청 기준 직선거리입니다.
- 실제 차량 연동(위 콘셉트 설명 참고)
- 푸시 알림. 알림 화면은 예시입니다.
- 사진 GPS 읽기의 한계. Android 사진 선택기는 개인정보 보호를 위해 사진의 위치 정보를 지울 수 있습니다. 그러면 위치 자동 제안이 나타나지 않으므로, 시·군 검색이나 지도 핀으로 위치를 정해야 합니다.
