# 수정 반영 기록 (2026-11-14)

「파킷 앱 수정 사항 및 개선안」(2026-11-14) 문서의 항목을 코드에 반영한 결과입니다. Windows의 Pleos Connect Emulator 2.1.0과 휴대폰 에뮬레이터에서 직접 눌러 확인했고, 단위 테스트 55개가 통과합니다.

## 휴대폰 지도와 장소 공유

| 항목 | 반영 내용 | 확인 |
| --- | --- | --- |
| 지역 선택과 지도 이동 | 지역을 누르면 지도가 그 지역으로 이동하고 임시 핀이 중심에 놓입니다. 지도를 누르면 핀이 그 좌표로 옮겨지고 그 좌표가 저장됩니다. '시·군까지만'을 고르면 게시물에는 시·군 중심만 저장된다고 안내합니다. | 가평, 양평을 연속으로 눌러 지도와 핀이 함께 바뀌는 것을 확인 |
| 위치부터 시작하는 장소 공유 | 순서를 위치 → 사진 → 이야기로 바꿨습니다. 첫 화면에 '내 위치에서 시작'이 있고, 권한을 거부하면 지도에서 찍으라고 안내합니다. 공유 지도에 기존 장소가 보이며, 그 사진을 누르거나 300m 안에 핀을 찍으면 '이 장소에 후기 남기기'가 나와 상세의 후기 입력으로 이동합니다. | 자라섬 캠핑장을 눌러 후기 화면으로 이동, 새 장소가 만들어지지 않는 것을 확인 |
| 대표 사진 | 샘플 장소 두 쌍이 같은 대표 사진을 쓰고 있어 중복으로 보였습니다(제천과 영월, 양평과 하동). 영월과 하동에 다른 사진을 넣어 장소마다 대표 사진이 다릅니다. 고르는 중인 위치는 사진 마커가 아니라 핀으로 그려 기존 장소를 가리지 않습니다. | 지도에서 확인 |
| 시설 조건 | 조건을 켜면 칩 아래에 '조건 N개 적용 · M곳'과 '조건 지우기'가 나옵니다. 시설 칩은 방문자가 '괜찮아요'로 확인한 곳만 남깁니다. 이전에는 '준비하세요'(예: "주변에 화장실이 없어요")도 있는 것으로 쳤습니다. 정보가 없는 곳과 없다고 한 곳이 모두 빠진다는 설명을 함께 보여줍니다. | 화장실+전기 0곳, 화장실만 5곳 |
| 준비물 입력 | 직접 구매/광고·제휴 선택 버튼을 없앴습니다. 이름이나 써 본 이유 중 하나만 적어도 추가됩니다. 기존 게시물에 저장된 광고·제휴 값과 표시는 그대로입니다. | 빌드 확인, 화면에서 추가까지는 눌러 보지 않음 |

## 상세 화면과 장소 전송

| 항목 | 반영 내용 | 확인 |
| --- | --- | --- |
| 방문 기록과 차박 상태 제보 | '방문 기록(나만 봐요)'과 '차박 상태 제보(모두에게 보여요)'를 별도 상자로 나눴습니다. 제보는 상태를 고른 뒤 '제보 제출'을 눌러야 접수되고, 제출 전에 공개 범위와 반영 시점을 안내하며, 제출 뒤 접수 내용이 상자에 남습니다. '현장 확인'은 '현장 확인 필요'로 바꾸고 "차박이 허용된 곳이라는 뜻이 아니에요"를 덧붙였습니다. | 제보 제출과 접수 표시 확인 |
| 양방향 장소 전송 | 휴대폰 상세와 차량 탭에 전송 대기 / 전송 성공 · 수신 대기 / 차량 수신 / 길 안내 시작을 구분해 표시합니다. 로그인이나 차량 연결이 없으면 대기 이유와 다음 행동(차량 연결하러 가기)을 보여주고, 실패하면 이유와 함께 다시 누르라고 안내합니다. 차량은 새 장소를 받으면 장소 이름과 '장소 열기' 버튼이 있는 알림을 7초간 띄웁니다. 차량에서 보낸 항목이 도착하면 휴대폰이 알림 위치를 알려 줍니다. | 휴대폰 → 차량: 수신 대기 → 차량 수신, 차량의 '장소 열기' 확인. 차량 → 휴대폰 알림 문구는 화면에서 보지 못함 |
| 장소 도우미와 화면 문구 | 두 앱 상세에서 장소 도우미 버튼과 대화창을 제거했습니다. 방문 팁과 공식 장소 정보는 기존 꿀팁 영역에 그대로 있습니다. 지역과 테마를 별도 라벨로 나눴고, '바다와 노을'은 '해안·노을'로 바꿨습니다. 차량 검색창 문구는 '장소, 지역, 작성자 검색'입니다. 주행 중 음성 질문(주차, 야간 이용 등)은 그대로 답합니다. | 두 앱 상세 확인 |
| 꿀팁 제보 입력과 키보드 | 상세 화면 전체가 키보드 높이만큼 올라가고, 입력란에 포커스가 가면 그 입력란이 보이는 곳으로 스크롤합니다. 입력 중에는 하단 탭 바를 숨깁니다. | 키보드가 열린 상태에서 요약, 자세히 입력과 제보하기 버튼까지 확인 |

## 차량 지도와 버튼 동작

| 항목 | 반영 내용 | 확인 |
| --- | --- | --- |
| 내 위치와 선택 장소 이동 | 조준점 아이콘은 항상 내 위치로 갑니다. 선택한 장소로 가는 동작은 장소를 골랐을 때만 나오는 핀 아이콘 버튼으로 분리했습니다. 내비게이션에서 위치를 받지 못했으면 위치 점을 그리지 않고 "현재 위치를 알 수 없어요"라고 알립니다. 휴대폰 지도의 조준점도 내 위치로 이동합니다. | 강릉이 선택된 상태에서 조준점 → 현재 위치(판교)로 이동 |
| 파킷 기능 노출과 선택 상태 | 메뉴 이름을 '파킷하기'로 바꿨습니다. 지도, 저장, 다녀온 곳, 휴대폰, 계정으로 이동하거나 장소를 열면 배너가 닫히고, 배너가 열려 있는 동안에는 '파킷하기'만 강조됩니다. 배너 안내에 누르면 무엇이 저장되고 휴대폰에서 무엇을 보는지 적었고, '말로 메모'는 '음성 메모'로 바꿨습니다. | 배너를 연 뒤 저장, 지도를 눌러 닫히는 것을 확인 |
| 주행 화면 미리보기 | 메뉴 이름을 '주행 화면 미리보기'로, 화면 머리말을 '주행 화면 미리보기 · 정차 중'으로 바꿨습니다. 경로가 없으면 길 안내를 시작했을 때 표시될 정보 세 가지를 안내합니다. 닫기 버튼은 '미리보기 닫기'입니다. | 경로가 있는 상태만 확인. 경로 없는 안내 화면은 화면에서 보지 못함 |
