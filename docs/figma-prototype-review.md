# Figma 프로토타입 검토 — 낭만로드

팀이 Figma Make 프롬프트(가칭 '차박스팟')로 만든 차박 장소 공유 SNS 프로토타입을 직접 눌러 보고, 원래 프롬프트에서 요청한 화면·흐름과 비교한 결과입니다. 다음 프롬프트를 작성하거나 실제 앱 범위를 정할 때 참고합니다.

- [Figma Make 파일: 차박 장소 SNS 플랫폼](https://www.figma.com/make/opZJeRfGAC1fQkmAmJFu8L/%EC%B0%A8%EB%B0%95-%EC%9E%A5%EC%86%8C-SNS-%ED%94%8C%EB%9E%AB%ED%8F%BC)

> 확인 범위: 2026-11-05 Figma Make 미리보기(버전 1)를 브라우저에서 열어 차량 디스플레이와 모바일 앱 화면을 직접 클릭해 확인했습니다. 도어 카드, 음성 검색, 지도 확대·축소, 장소 상세의 좋아요·저장·팔로우·공유 버튼, 앨범 사진, 모바일 지도 핀과 마이 화면의 마커는 확인하지 않았습니다.

## 요약

생성된 서비스 이름은 프롬프트의 가칭 '차박스팟'이 아니라 **낭만로드**입니다. 어두운 배경, 코랄 포인트 색상, 사진 중심 카드 등 디자인 방향은 프롬프트와 잘 맞습니다.

처음부터 끝까지 클릭으로 진행되는 흐름은 세 가지입니다.

- 차량: 지도에서 장소 발견 → 장소 상세 → 길 안내
- 모바일: 장소 공유 4단계 → 게시 완료
- 모바일: 공조 켜기 → 확인 창 → 결과 표시

나머지는 대부분 화면만 있고 눌러도 반응이 없습니다. 프롬프트의 제작 화면 22개 중 9개가 있고, 3개는 일부만 있으며, 10개는 없습니다.

## 차량 디스플레이

### 동작하는 흐름

1. 지도에서 사진 핀을 누르면 핀이 강조되고, 하단 미리보기 카드가 그 장소로 바뀝니다.
2. 카드의 `>` 버튼을 누르면 장소 상세가 열립니다. 왼쪽은 대표 사진(`1 / 8`)과 감상, 오른쪽은 작성자·주소·거리와 탭입니다.
3. '방문 꿀팁' 탭에는 주차·화장실·통신·야간 카드, '방문자 한마디', '도움이 됐어요 28', '최근 확인 3일 전'이 표시됩니다.
4. '이 낭만을 만든 아이템' 탭에는 상품 카드가 있습니다. '휴대폰에서 보기'를 누르면 "상품 링크를 휴대폰으로 보냈어요" 토스트가 표시됩니다.
5. '길 안내 시작'을 누르면 "차량 내비게이션으로 목적지를 전송했어요" 토스트가 표시됩니다.
6. 사이드바의 '앨범'을 누르면 4열 사진 그리드가 열리고, '지도' 버튼으로 돌아갈 수 있습니다.

### 화면만 있고 반응이 없는 부분

- 지도 필터 칩: 선택 표시만 바뀌고 지도 핀은 걸러지지 않습니다.
- 오른쪽 피드의 인기·최신·팔로잉 탭과 앨범의 추천·팔로잉·최신·저장한 장소 탭
- 사이드바의 '저장', '마이'와 알림 벨
- 꿀팁 카드: `>` 표시가 있지만 상세가 열리지 않습니다.
- 피드 카드: 어느 카드를 눌러도 같은 "강릉의 조용한 노을 명소" 상세가 열립니다.

## 모바일 앱

하단 내비게이션은 프롬프트대로 홈·지도·장소 공유·차량·마이 다섯 개입니다.

### 동작하는 흐름

**장소 공유 4단계**

1. 사진 선택
2. 장소 지정: 사진의 위치를 자동으로 찾아 표시합니다.
3. 제목과 경험 작성: "해시태그 대신 실제 경험을 들려주세요."라는 안내가 있습니다.
4. 꿀팁 선택(주차·화장실·전기·통신·야간·접근성)과 한 줄 꿀팁 입력

'낭만 공유하기'를 누르면 홈으로 돌아가고 "새로운 낭만이 지도와 피드에 공개됐어요" 토스트가 표시됩니다.

**내 차량**

- IONIQ 5, 주차 중, 배터리 72%, 주행 가능 거리 310km, 충전 상태가 표시됩니다.
- 도어(잠김), 공조(꺼짐), 실내 온도(26°C), 무드 조명(지원 안 함) 카드가 있습니다.
- 공조의 '켜기'를 누르면 "공조를 켜시겠어요?" 확인 창이 열립니다. 확인하면 카드가 "22°C · 켜짐"으로 바뀌고 "차량 공조가 시작됐어요" 토스트가 표시됩니다.

### 화면만 있는 부분

- 홈 피드: '나를 위한 추천' 게시물과 '이번 주말, 가까운 곳' 목록이 있습니다. 게시물이나 댓글 수를 눌러도 상세가 열리지 않습니다.
- 지도: 사진 핀과 하단 장소 카드만 있습니다.
- 마이('나의 낭만'): 프로필(공유 장소·방문 완료·받은 좋아요)과 내 장소 지도가 있습니다. 지도 아래에 공유·저장·방문 완료 마커 범례가 있습니다.

## 우선 보완할 부분

1. **주행 중 간소화 화면이 없습니다.** 프롬프트와 Pleos 차량 UI 가이드 모두 운전 중 시각적·인지적 부담을 줄이도록 요구합니다. 정차 중과 주행 중을 전환해 보여주는 화면이 하나만 있어도 기획의 설득력이 커집니다.
2. **모바일 차량 제어가 실제로 연결된 것처럼 보입니다.** 화면에는 "PLEOS CONNECTED · 안전하게 연결됨"만 표시됩니다. 프롬프트에서는 승인된 연동 수단이 확보되기 전까지 프로토타입 상태로 표시하기로 했으므로, 콘셉트 화면이라는 표시를 추가하는 것이 안전합니다.
3. **꿀팁 기능이 절반만 있습니다.** '도움이 됐어요'와 최근 확인 날짜는 있지만, 방문자의 꿀팁 제안과 정보가 엇갈릴 때의 '확인 필요' 표시는 없습니다. 꿀팁은 이 서비스의 핵심 차별화 요소입니다.
4. **차량과 휴대폰의 연결이 토스트에서 끝납니다.** '휴대폰에서 보기' 이후 모바일에서 그 장소 상세가 열리는 장면과, 저장한 장소가 양쪽에 반영되는 장면이 없습니다. 그래서 '하나의 계정' 경험이 화면에 드러나지 않습니다.

## 그 밖에 빠진 부분

- 장소 공유에서 추천 아이템 연결과 공개 범위 설정 단계가 빠졌습니다.
- 지도 필터 7개 중 '드라이브 명소'와 '조용히 쉬기 좋은 곳'이 없습니다.
- 상품 카드에 가격, 추천 이유, 유료 제휴·광고 표시가 없습니다.
- 커뮤니티 기능(댓글, 대댓글, 질문하기, 알림)을 보여주는 화면이 없습니다.

## 샘플 데이터 불일치

- 같은 강릉 게시물이 차량에서는 "강릉의 조용한 노을 명소", 모바일에서는 "파도 소리만 들리는 강릉의 작은 해변"입니다.
- 모든 장소의 거리가 "42km"로 같습니다.
- 꿀팁 배지는 7개인데 카드는 4개와 방문자 한마디 1개만 있습니다. 아이템 배지는 4개인데 카드는 3개입니다.
- 서비스 이름을 '낭만로드'와 '차박스팟' 중 하나로 정해야 합니다.

## 실제 앱으로 옮길 때 참고

- '길 안내 시작'은 Pleos NaviHelper의 목적지 설정 기능으로 구현할 수 있는지 확인합니다. 사용 가능 상태는 [Pleos SDK 사용 안내](https://document.pleos.ai/docs/pleos-only/create-my-project)에서 확인합니다.
- Pleos Connect SDK는 차량 안의 Android Automotive 앱에서 차량 정보를 조회하고 제어하는 구조입니다. 스마트폰에서 원격 제어하는 공개 SDK는 확인되지 않았으므로, 모바일 '내 차량' 화면은 콘셉트로 다룹니다.
- 주행 중 화면 제한은 차량 앱에서 주행 상태를 읽어 전환하는 방식으로 설계합니다. 사용할 수 있는 차량 상태 정보는 개발 전에 공식 문서에서 확인합니다.
