# 동기화 서버

차량 앱과 휴대폰 앱이 같은 계정의 데이터를 쓰도록 이어 주는 개발용 서버입니다. 코드는 `server/` 모듈에 있습니다. 서버와 두 앱이 함께 쓰는 데이터 모델과 API 계약은 `shared/` 모듈에 있습니다.

> 개발·시연용입니다. 닉네임과 비밀번호로 가입·로그인하고(샘플 계정은 공통 데모 비밀번호 `parkit-demo`), 비밀번호는 PBKDF2 해시로 저장하며, 세션 토큰은 90일 동안 쓰지 않으면 만료됩니다. 차량 연결 코드는 10분 안에 5번 틀리면 잠깁니다. 다만 HTTP로 통신하고 데이터는 JSON 파일 하나에 저장하니 인터넷에 공개하지 마세요.

## 실행

저장소 루트에서 실행합니다. 서버는 8080 포트에서 기다립니다.

macOS:

```zsh
sh gradlew :server:run
```

Windows PowerShell:

```powershell
.\gradlew.bat :server:run
```

`PARK-IT sync server: http://localhost:8080` 메시지가 나오면 준비된 것입니다. `curl http://localhost:8080/health`가 `ok`를 돌려주면 정상입니다.

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `8080` | 서버 포트 |
| `NANGMANROAD_DATA` | `server/data` | 계정, 게시물, 사진을 저장하는 폴더. git에서 제외됩니다. |

데이터를 처음 상태로 되돌리려면 서버를 끄고 `server/data` 폴더를 지웁니다. 그러면 이미 로그인한 기기는 다음 요청에서 자동으로 로그아웃됩니다.

## 앱이 서버를 찾는 방법

두 앱은 빌드할 때 정한 주소로 접속합니다. 기본값은 `http://10.0.2.2:8080`이고, 에뮬레이터에서 이 주소는 개발용 PC의 `localhost`를 가리킵니다. 실제 휴대폰이나 차량에서 시험하려면 PC의 LAN 주소로 다시 빌드합니다.

```zsh
sh gradlew -Pnangmanroad.syncUrl=http://192.168.0.10:8080 :phone:assembleDebug :vehicle:assembleDebug
```

앱은 개발 서버의 HTTP 통신을 `10.0.2.2`와 `localhost`에만 허용합니다(`res/xml/network_security_config.xml`). LAN 주소를 쓰려면 그 파일에 주소를 추가해야 합니다.

## 계정과 차량 연결

1. **휴대폰:** 앱을 처음 열면 닉네임을 묻습니다. `윤슬을따라`는 샘플 게시물(태안)이 있는 데모 계정이고, 새 닉네임을 넣으면 새 계정이 만들어집니다. '서버 없이 둘러보기'를 고르면 예전처럼 기기 안에만 저장합니다.
2. **차량:** 사이드 레일의 **계정 연결**을 누르면 6자리 코드가 나옵니다. 코드는 10분 동안 유효하고, 시간이 지나면 새 코드로 바뀝니다.
3. **휴대폰:** **차량** 탭 > **차량 연결**에 그 코드를 입력합니다.
4. 차량 화면이 2초 안에 계정 이름으로 바뀝니다. 연결된 차량은 휴대폰과 같은 계정으로 동작합니다.

차량에서 **연결 해제**를 누르면 그 차량만 로그아웃되고 새 코드가 나옵니다.

## 동기화되는 것

| 항목 | 휴대폰 → 차량 | 차량 → 휴대폰 |
| --- | --- | --- |
| 저장한 장소, 좋아요, 팔로우, '도움이 됐어요' | ✓ | ✓ |
| 새 게시물(사진 포함), 댓글, 제보한 꿀팁 | ✓ (지도·피드·앨범에 표시) | 차량에서는 작성하지 않음 |
| 차량으로 보내기 | 차량의 **휴대폰** 메뉴(앨범 '휴대폰에서 보냄' 탭)에 표시 | |
| 휴대폰으로 보내기(장소, 상품, 꿀팁 제보, 댓글 쓰기) | | 휴대폰 **알림**의 '차량에서 보낸 항목'에 표시 |
| 파킷(차량이 세운 위치와 시각) | | 같은 목록에 핀으로 표시. `SentItem.location`에 좌표가 실리고 id는 `parkit:`으로 시작 |
| 방문 완료, 관심 상품 | 휴대폰에서만 씀 | |

두 앱은 서버를 주기적으로 다시 읽습니다. 휴대폰은 앱이 화면에 있을 때 10초마다, 차량은 정차 중일 때 10초마다 읽습니다. 그래서 다른 기기의 변화는 최대 10초 뒤에 보입니다. 차량은 휴대폰에서 새 장소를 보내면 알림을 띄웁니다. 주행 중에는 화면이 바뀌지 않도록 읽지 않습니다.

좋아요·저장·'도움이 됐어요' 수는 서버가 다른 사용자 수를 합쳐서 돌려주고, 앱이 내 것을 더합니다. 그래서 서버 없이 쓸 때와 같은 방식으로 숫자가 바뀝니다.

## API

경로와 요청·응답 형식은 `shared/src/main/kotlin/com/nangmanroad/core/sync/Api.kt`의 표에 정리되어 있습니다. 로그인, 차량 연결 코드, 사진 조회를 뺀 모든 요청에는 `Authorization: Bearer <토큰>` 헤더가 필요합니다. 사진은 `POST /api/photos`에 이미지 바이트를 그대로 보내면 `/photos/<이름>.jpg` 경로를 돌려줍니다(15MB까지).

## 테스트

```zsh
sh gradlew :server:test :core:testDebugUnitTest
```

- 서버 테스트 8개: 로그인, 수 집계, 차량 연결과 코드 만료, 팔로워 공개 범위, 댓글 답글, 재시작 후 데이터 유지, HTTP 인증
- 클라이언트 테스트 4개(`SyncClientTest`): JSON 본문과 형식 헤더, 토큰 헤더, 오류 메시지, 사진 주소 변환

## 아직 없는 것

- HTTPS(서버 앞에 Caddy·ngrok 등), 소셜 로그인, 비밀번호 재설정
- 운영 배포. 지금은 개발용 PC에서만 실행합니다.
- 실시간 알림. 지금은 10초 간격으로 다시 읽습니다.
- 여러 기기에서 동시에 같은 목록을 바꿀 때의 충돌 처리. 마지막 요청이 이깁니다.
