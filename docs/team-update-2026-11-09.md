## 알아둘 것

- 코드·패키지 이름은 그대로 `com.nangmanroad`(낭만로드)입니다. NAVER 지도 키가 이 패키지에 등록되어 있어 바꾸면 지도가 멈춥니다.
- NAVER 지도 키는 각자 `local.properties`에 `naver.ncpKeyId=…`로 넣습니다(저장소에 없음). 키가 없으면 캔버스 지도로 동작합니다. 방법: `docs/development-setup.md`
- 차량 앱은 매니페스트에 `CAR_ENERGY`, `CAR_INFO` 권한이 추가됐습니다(배터리 읽기). 에뮬레이터는 용량을 Wh로 주어 kWh로 보정합니다.
- `shared` 모듈을 다시 빌드하면 동기화 서버도 재시작해야 합니다(안 하면 500).
- 전비는 5 km/kWh 고정 가정입니다.

## 남은 것 (백로그)

- 출발 알림 배너("늦어도 오후 1:30 출발"이 다가오면 알리기)
- 실제 전비 연동(`getCurrentEvEfficiency`)으로 도착 잔량 보정
- 날씨·월령, 경로형 게시물, 다녀온 날짜 타임라인, 재제보 근거 입력, 차량 앨범 시설 칩, 필터 선택 유지

## 직접 보려면

```
git pull
.\gradlew.bat :server:run            # 동기화 서버 (다른 터미널)
.\gradlew.bat :vehicle:assembleDebug :phone:assembleDebug
```

차량 에뮬레이터(Pleos Connect 2.1.0)와 휴대폰 에뮬레이터에 설치한 뒤, 휴대폰은 닉네임 `윤슬을따라`로 들어가고 차량은 "계정 연결"의 6자리 코드를 휴대폰 차량 탭에 입력하면 연결됩니다.
